# Data Marketplaces — Focus List

**Curated**: 2026-02-26
**Source**: `research/data-marketplaces.md` (127 platforms surveyed)
**Purpose**: Mine these marketplaces for category/taxonomy intelligence — what categories do they use to organize datasets?

> **Selection criteria**: Generalist (not niche to one industry/geography), mature (established, not early-stage), large catalog (many datasets and/or providers). These are the marketplaces most likely to have well-developed, broad category taxonomies worth studying.

## Focus List

| # | Platform | Type | Scale | Why Selected |
|---|----------|------|-------|--------------|
| 1 | AWS Data Exchange | Cloud marketplace | ~3,500 products, 300+ providers | Largest cloud-native data marketplace; covers all industries/geographies |
| 2 | Snowflake Marketplace | Cloud marketplace | ~2,000+ listings, 500+ providers | Second-largest cloud marketplace; strong cross-industry coverage |
| 3 | Databricks Marketplace | Cloud marketplace | ~1,500+ listings | Third major cloud marketplace; open protocol (Delta Sharing); cross-industry |
| 4 | Google Cloud Analytics Hub | Cloud marketplace | 200+ public datasets + commercial | Google's data exchange; BigQuery ecosystem; broad category coverage |
| 5 | Datarade | Aggregator/directory | 2,000+ listed providers | Meta-marketplace aggregating all categories; best view of the full landscape |
| 6 | Kaggle Datasets | Community/ML | 200,000+ datasets, 15M+ users | Largest community dataset platform; extremely broad topic coverage |
| 7 | Hugging Face Datasets | Community/ML | 100,000+ datasets | Dominant ML dataset hub; wide variety of data types and domains |
| 8 | Nasdaq Data Link (Quandl) | Financial + alt data | Hundreds of datasets, many free | Two-sided marketplace with structured categories; finance-heavy but broad |
| 9 | Google Dataset Search | Meta-search engine | 25M+ datasets indexed | Indexes datasets across the entire web; broadest category view possible |
| 10 | Narrative.io | Data commerce platform | Billions of data points | Programmatic data marketplace with structured attribute taxonomy; cross-category |

## Rationale for Exclusions

| Category | Why Excluded |
|----------|-------------|
| Government/civic portals (Data.gov, data.europa.eu, etc.) | Geographically scoped to one country/region; not commercial marketplaces |
| International org data (World Bank, IMF, OECD, etc.) | Single-provider portals, not marketplaces; domain-specific (economics/development) |
| Sector-specific providers (IQVIA, ATTOM, Lightcast, etc.) | Niche to one industry (healthcare, real estate, labor) |
| Financial data terminals (Bloomberg, Refinitiv, S&P) | Finance-only; not multi-industry marketplaces |
| Consumer/marketing data (Acxiom, Experian, LiveRamp, etc.) | Niche to advertising/identity; not general-purpose |
| Location data (Foursquare, Placer.ai, SafeGraph/Dewey) | Niche to location intelligence |
| Blockchain/decentralized (Ocean Protocol, The Graph, etc.) | Immature, niche to crypto/Web3 |
| Academic repositories (Zenodo, Figshare, Dryad, etc.) | Research-focused, not commercial marketplaces |
| Data labeling platforms (Scale AI, Labelbox, Appen) | Services, not dataset marketplaces |
| Azure Data Marketplace | Fragmented, smaller data catalog compared to AWS/Snowflake |
| SAP Data Marketplace | Enterprise-locked (SAP ecosystem only) |
| IBM Data Exchange | Small (~30-50 datasets), mostly discontinued |
| Oracle Data Marketplace | Largely discontinued |

## Notes

- The top 4 (AWS, Snowflake, Databricks, Google) are the **cloud data marketplaces** — these are our primary competitors/distribution channels per the business thesis
- Datarade and Google Dataset Search are **meta-level** views — they aggregate across marketplaces and can reveal the broadest category landscape
- Kaggle and Hugging Face represent the **community/open** data ecosystem — useful for understanding what categories have demand from data scientists
- Nasdaq Data Link and Narrative.io are **commercial two-sided marketplaces** with structured taxonomies worth studying
